About Linux support: HomRec's capture engine is currently built on Windows-only APIs (DXGI/D3D11/Win32). Native Linux support (X11 and Wayland capture) is planned and in active development, but there is no working Linux build yet — see the Linux status page for details.

What is HomRec?

If you've ever tried recording your screen with OBS or Bandicam on an old laptop or office PC and everything lagged — HomRec is made for you.

Written from the ground up to use the minimum possible CPU and RAM. No fancy effects, no GPU requirement, no background services. Just open, record, done.

HomRec is 100% native C/C++. There is no Python anywhere in this project — the entire app (UI, recording pipeline, audio, plugins, console) compiles directly into a single hr.exe with no runtime dependencies beyond FFmpeg.

Note: The program is new, so the system requirements may be very different from reality. If your computer can handle it, or can't handle it, please contact me.

Installation

Option A — Installer (recommended)

1. Download homrec-setup-win64-<version>.exe from Releases
2. Run it. It installs for your user only, no administrator rights needed
3. Start HomRec from the Start menu

Option B — Portable archive

1. Download the latest .zip or .7z from Releases
2. Unpack it into a folder you can write to (not C:\Program Files)
3. Launch hr.exe

FFmpeg: only the full archive (...-portable-full) contains it. With the plain portable archive, put ffmpeg.exe into an ffmpeg folder next to hr.exe, or HomRec reports "FFmpeg not found."

Antivirus warning? Some antiviruses flag HomRec because it is a new, unsigned program. It is not a virus — the full source code is on GitHub.

Step by step, with checks: Getting started guide.

Option C — Build from source

git clone https://github.com/homaaio/HomRec.git
cd HomRec
cmake -S . -B build -G "MinGW Makefiles"
cmake --build build -j

Requires the MSYS2 UCRT64 toolchain, wxWidgets 3.2, Lua 5.4 and CMake; FFmpeg is needed at run time. See the build guide.

Keyboard Shortcuts

Key (default) Action
F9 Start / Stop recording
F10 Pause / Resume recording
F11 Toggle HomRec's own window fullscreen
F8 Save Instant Replay
Ctrl+Shift+T Open the built-in console

The four function keys can be changed in Settings > Hotkeys.

Troubleshooting

Problem Solution
"Windows protected your PC" (SmartScreen) Click More info → Run anyway
Antivirus flags the file False positive. Add the HomRec folder to the exclusions
"FFmpeg not found." You use the plain portable archive. Add ffmpeg\ffmpeg.exe next to hr.exe
"...dll was not found" at launch Unpack the whole archive again; do not copy hr.exe alone
Black screen instead of video Check the capture source first; if a program runs as administrator, run HomRec as administrator too. See the guide
Video lags or stutters Use a hardware encoder, lower the frame rate or the resolution
No sound in recording Check the Audio Mixer bars and the microphone in Settings > Audio
Anything else Read the end of logs\homrec.log; see Logs and diagnostics
