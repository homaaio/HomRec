Quick answers

Click a problem to read the short answer. Each links to the full guide.

HomRec does not start or closes immediately

Only one copy runs at a time, so look in the system tray first. If Windows says a .dll was not found, unpack the whole archive again. For a crash, attach the newest file from crashes\ and the end of logs\homrec.log to a bug report.

Full guide →

"FFmpeg not found."

HomRec encodes with ffmpeg.exe. Only the full portable archive contains it. Put ffmpeg.exe into an ffmpeg folder next to hr.exe.

Full guide →

Start shows "Output folder doesn't exist" or "Not enough free disk space"

Pick a writable folder in Settings > General > Output folder. Recording needs at least 200 MB free on the output drive.

Full guide →

The recording is black, frozen or shows the wrong thing

Check whether the preview is also black (capture problem). Remote Desktop and virtual displays cannot be captured. Re-select the monitor by double-clicking the first row of the Layers panel. For a window, use the Test: find it now button.

Full guide →

There is no sound, or the wrong sound

Watch the Audio Mixer bars: if they move, the source works. Check the mute button and Settings > Audio > Microphone, and use Test. Program-sound capture needs Windows 10 version 2004 or newer.

Full guide →

The recording stutters or the game loses FPS

Use a hardware encoder, lower the frame rate or the resolution, and enable Game-friendly priority. Change one thing at a time and compare the frame counts in the log. Recording overloaded in the log means HomRec dropped frames.

Full guide →

NVENC, AMF or Quick Sync does not work

HomRec never swaps your chosen codec silently: it shows a notice and logs the reason. With HW accel = auto it tests NVENC, AMF and QSV and falls back to libx264 for recordings only.

Full guide →

The .mp4 will not open after a crash

MP4 is only complete when it is finished. Record as MKV (it survives crashes) or choose Both.

Full guide →

Hotkeys do not work

Defaults are F9 start/stop, F10 pause, F11 fullscreen of HomRec's window and F8 save replay. Another program may use the same key; change it in Settings > Hotkeys.

Full guide →

Instant Replay says "Instant Replay isn't running."

Tick Enable Instant Replay in Settings > Advanced and set a buffer length. Replay is paused while a normal recording runs and resumes afterwards.

Full guide →

The window is recorded as a screen crop

After a crash inside native window capture, HomRec switches it off. Open the Capture source window and click Try the native Windows capture again....

Full guide →

The console says: blocked - needs the "inwid" confirmation prefix

Changing a setting, switching a preset, rm and risky hom commands need the prefix: inwid target_fps = 60.

Full guide →

A plugin does nothing

Turn on Plugin logging in Settings > Security and read logs\plugins.log. A hook must be a global function with the exact name.

Full guide →

hom is not found or cannot download

Run hom restore in the console to download hom.exe again, or copy it next to hr.exe by hand.

Full guide →

Update says "No installer was found in that release"

The release has no Setup .exe attached. Download from the release page. A portable copy cannot update itself: replace the files and keep homrec.hrc, presets\, scenes\, plugins\ and cfg\.

Console and cfg scripts

Open the console with Ctrl+Shift+T (Help > Console). Reading a setting is free (target_fps). Changing one, switching a preset, rm and risky hom commands need the inwid prefix:

target_fps
inwid target_fps = 60
inwid preset gaming

Two optional scripts in cfg\ next to hr.exe: autoexec.cfg runs at every launch, startrec.cfg at the start of every recording. One command per line; // and # start comments. Lines in these scripts run as confirmed, so they do not need inwid.

Dangerous: inwid rm --system@homrec.files --type=... deletes whole folders next to hr.exe, and inwid rm @homrec -r -y removes HomRec itself. It also needs sec 0. --type=recordings removes the folder named recordings next to hr.exe, not your configured output folder.

Full reference: Console reference.

Plugins

Plugins are Lua scripts in plugins\ with a plugin.json and an entry script. They have full file and network access, so install only plugins you trust. Install by importing a .hrp (File > Import Plugin), by copying it into plugins\, or with hom install.

HookCalled when
on_load / on_unloadThe plugin is loaded / unloaded
on_recording_start / on_recording_stopA recording starts / stops
on_replay_savedAn Instant Replay clip is saved
on_overlay_added / on_overlay_removedAn overlay is added / removed
on_custom_eventAnother plugin raised an event

The homrec.* API, the manifest and the failure table: Plugins guide.

hom, the package manager

hom is a separate program, developed in its own repository. HomRec's console forwards hom ... to hom.exe in the HomRec folder; plugins it installs land in plugins\ and load at the next start. If hom.exe is missing, hom restore downloads it again.
