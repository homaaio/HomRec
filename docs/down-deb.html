Installation

From .deb package (recommended):
1. Download the .deb file
2. Install via terminal: sudo dpkg -i homrec-v2.0-linux-amd64.deb
3. Run hr from your applications menu or terminal.

From .tar.gz archive:
1. Download and extract: tar -xzf homrec-v2.0-linux-x86_64.tar.gz
2. Navigate to the folder: cd homrec-v2.0
3. Run ./hr
