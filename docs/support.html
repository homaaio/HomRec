Writing a good bug report

To get your issue resolved quickly, please include:

  1. HomRec version (Help > About, or version in the built-in console) and whether it is the installer or a portable copy
  2. Windows version (10/11, 64-bit), and your graphics card with its driver version
  3. A brief description of the problem
  4. Steps to reproduce it
  5. The file logs\homrec.log (or its last 200 lines); for a crash, also the newest .dmp from crashes\
  6. For a recording problem: the codec, container and capture source you used

Logs can contain file paths and window titles. Look through them before you post them.

Response time: usually within 2–4 days. HomRec is an open-source project maintained in spare time, so please be patient.

Security

Never include passwords, license keys, or other sensitive data in a public GitHub issue. If you find a security vulnerability, please email homa4ella@gmail.com directly instead of opening a public issue.
