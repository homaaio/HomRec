Installation

Installer (homrec-setup-win64-<version>.exe): run it and start HomRec from the Start menu. No administrator rights are needed.

Portable archive: extract to a folder you can write to (e.g., D:\HomRec), then run hr.exe.

FFmpeg: only the full archive (...-portable-full) contains it. With the plain portable archive, put ffmpeg.exe into an ffmpeg folder next to hr.exe.
